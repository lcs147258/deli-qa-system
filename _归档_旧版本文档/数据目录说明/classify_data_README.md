# BERT 意图分类器训练数据

- 生成提示词：《提示词模块_熟食版.txt》（改自教育版同款方法）。
- 目标文件：`deli_classifier_500.json`，JSONL 格式，150 条通用知识 + 350 条专业咨询，
  必须包含提示词里列出的边界样本。
- 生成后人工抽查 30 条（重点抽边界样本），错误率 >5% 就重生成对应子集。
- 训练入口：`rag_qa/core/query_classifier.py` 的 `train_model()`（M3 阶段执行）。
- ⚠️ 本项目 `../models/bert_query_classifier/` 是教育版分类器的**实体副本**，
  重训后会被覆盖——这正是复制而非共享的原因，不要删。
